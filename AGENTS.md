# Contributor instructions

Read README.md, CONTRIBUTING.md and NOTICE.md before changing behavior. All provider access stays read-only. Tests run with `python -m pytest tests` and must not contact live services. Keep examples synthetic and do not add manager identifiers, credentials or local machine paths. Preserve explicit missing-data and scoring limitations. Run the installed offline demo when changing packaging or the CLI. Python 3.11 is the minimum supported version.
