# Reporting a security problem

> **TL;DR:** Do not post credentials, private league data or exploit details in public issues. Use this repository's private vulnerability reporting feature.

Open the repository's **Security** tab, choose **Report a vulnerability**, and describe the affected version and a minimal synthetic reproduction. If the option is unavailable, open a public issue asking for a private contact route without disclosing the vulnerability or personal data.

This is a local, single-user CLI. Cache files and generated reports can contain private information. Do not expose the cache, config directory or output as a public web folder. Review dependency and release changes before updating your personal installation.
